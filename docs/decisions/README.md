# Decision records

This folder holds short records of design decisions for the atServer: what was decided, why, and what else was considered. Each record is one file named `YYYY-MM-DD-topic.md` with a status (Proposed, Accepted, Superseded). Behaviour that a decision fixes is pinned by acceptance scenarios under `features/`, and each record names the feature file that does so.
